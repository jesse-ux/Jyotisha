# Sahams 执行指南

> 版本：v1.0 | 2026-06-26
> 作用：说明当前 skill 中 Sahams 的实际落地方式、阅读顺序与边界。

## 一、当前已具备的落点

当前 skill 中，Sahams 不是只停留在概念层，已经落在：

1. `scripts/tajika.py`
2. `scripts/varshaphala.py`
3. `scripts/solar_return.py`
4. `scripts/prashna.py`
5. `scripts/jyotish_engine.py`
6. `vivah-saham` 专用入口

## 二、当前常见使用场景

1. **年运盘辅助定位**
   - `Varshaphala / Tajika`
2. **婚恋专题辅助**
   - `Vivah Saham`
3. **Prashna 辅助证据层**
   - 与 `Sphuta / timing score` 组合使用

## 三、当前推荐阅读顺序

### 场景 A：年运

1. Solar Return / Muntha / Varshesha
2. Tajika Yogas
3. 再看 Sahams
4. 最后与 Dasha / Transit 交叉

### 场景 B：婚恋

1. D1 / D9 / DK / UL / Dasha
2. 再看 `Vivah Saham`
3. 再看 Transit 是否触发该点

### 场景 C：Prashna

1. YES/NO 主结论
2. KP Horary evidence
3. 再看 `Sahams`
4. 不允许用 Saham 反客为主推翻主结论

## 四、当前真实边界

当前 skill 已能输出常见 36 个 Saham 与婚姻点等专项点。

但必须保留的边界：

1. Saham 适合做**辅助敏感点**
2. 不适合单独承担重大事件承诺
3. 权重、解释层与传统软件黑盒一致性仍未完全闭环
4. 涉及寿命、医学、法律等高风险主题时，只能作为侧证

## 五、当前推荐话术

- 适合说：
  - “Saham 指向某个敏感领域”
  - “Saham 与 Dasha/Transit 一致时，可提高关注度”
  - “Vivah Saham 可作为婚恋窗口的补充触发点”
- 不适合直接说：
  - “Saham 单独决定事件一定发生”
  - “Saham 已达到传统软件级最终校准”

## 六、一句话定位

**Sahams 在当前 skill 里已经是高价值补充证据层，但仍不是独立终裁器。**
