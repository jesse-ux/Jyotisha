## 二、这三者各自最适合做什么

| 技法 | 最适合的角色 |
| --- | --- |
| Pushkara | 吉化标记、细节加分层 |
| Vargottama | 稳定性 / 一致性加权层 |
| RTN | 深层动机 / D9 心理驱动力解释层 |

## 三、当前推荐执行顺序

1. **先看 D1 promise**
2. **再看 D9 dignity / reversal**
3. **再看 Vargottama**
   - 判断某颗星是不是 D1-D9 一致强化
4. **再看 Pushkara**
   - 判断是否存在细节层吉化
5. **最后看 RTN**
   - 用来解释深层动机、关系模式、欲望驱动、内在快乐来源

## 四、当前真实边界

### Pushkara

- 当前可作为“加分/保护”标记
- 不能单独代替主判断

### Vargottama

- 当前可作为稳定性增强证据
- 不能单独覆盖 Dasha / Transit / house lord 逻辑

### RTN

- 当前最适合作为解释层，而不是 timing 层
- 不能单独做事件承诺
- 适合婚恋、动机、人格深层模式说明

## 五、当前推荐话术

- 适合说：
  - “Vargottama 提高了该星表达的一致性”
  - “Pushkara 给这颗星提供了额外吉化”
  - “RTN 揭示这颗星更深层的动机方向”
- 不适合直接说：
  - “只因 Vargottama / Pushkara 就能确保事件发生”
  - “RTN 可以单独做精确 timing”

## 六、一句话定位

**Pushkara / Vargottama / RTN 在当前 skill 中都已经有价值，但它们属于高阶解释层和加权层，不是单独的主引擎。**
