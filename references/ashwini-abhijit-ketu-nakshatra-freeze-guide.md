## 0. 来源等级与使用原则

网上文章中关于 Ashwini、Abhijit、Ketu 星宿日的断语差异很大，本手册只把它们作为线索，不把单篇文章直接升级为硬规则。

### A级：稳定基础

- 27 Nakshatra 的度数、主星、神祇、Gana、动物、基本 Shakti。
- Panchanga / Muhurta 中 Nakshatra 作为择时因子的基础用法。
- Vimshottari 与其他 Nakshatra Dasha 对月亮星宿的依赖。

### B级：传统实践强参考

- Ashwini 的快速启动、治疗、急救、交通、先锋特征。
- Ketu 主宰的 Ashwini / Magha / Mula 带有“切断旧路径、快速启动、祖先/根源、非线性突破”的共同底色。
- Abhijit 在部分 Muhurta 传统中作为特殊胜利窗口使用，但不应混同为常规 27 Nakshatra 的本命性格星宿。

### C级：文章/课程/个案线索

- “某 Nakshatra 日一定不宜某类活动”
- “Abhijit 必然带来财富或神性激活”
- “Ashwini 必然是神医/极速成功”
- “Ketu 星宿日一定导致损失或事故”

这些只能进入风险提示或择时偏好，必须经过 Dasha、Transit、Varga、现实条件交叉确认。

## 1. 用途

本手册把用户关心的“娄宿 Ashwini 天赋特征”“Abhijit 财富/神性激活”“Ketu 星宿日规避/使用”整理为可执行模板。

适用场景：

1. 用户问天赋、职业风格、启动项目优势。
2. 用户盘中 Moon / Lagna / Atmakaraka / 10主 / 1主落 Ashwini、Magha、Mula。
3. 用户问某天是否适合启动、签约、疗愈、手术、旅行、公开发布。
4. 用户问 Abhijit Muhurta、特殊胜利窗口、紧急择时。
5. 用户问 Ketu 日、Ketu 星宿、Ketu Dasha 是否一定不吉。

## 2. Ashwini 天赋模板

### 基础定位

Ashwini：

- 度数：Aries 0°00' - 13°20'
- 主星：Ketu
- 神祇：Ashwini Kumaras，天界双生医师
- Gana：Deva
- 质量：Swift / Kshipra
- 动物：马
- 核心 Shakti：快速抵达、快速修复、快速启动

### 可以稳定使用的关键词

- 快速启动
- 急救/修复
- 医疗、疗愈、咨询
- 交通、速度、运动、马/车/移动工具
- 先锋、开局、试错、突破惯性
- 非传统入口

### 不可机械断言

不可以只凭 Ashwini 就说：

- 一定适合医生
- 一定富贵
- 一定早婚/晚婚
- 一定事故多
- 一定灵性很高

### 执行链

1. 看落点：Moon / Lagna / Sun / AK / AmK / 10主 / 1主是否在 Ashwini。
2. 看宫位：落 1/5/9/10/11 更容易外显成天赋；落 6/8/12 更偏疗愈、危机处理、隐秘修复。
3. 看主星 Ketu：Ketu 的宫位、定位星、相位、Dasha 激活决定 Ashwini 如何兑现。
4. 看火星：因 Ashwini 位于白羊座，Mars 状态会调节行动力与冲动风险。
5. 看分盘：D9 看内在动机，D10 看职业兑现，D24 看学习/技能，D60 只作高阶参考。

### 输出模板

低置信：

> Ashwini 给出快速启动和修复型天赋，但还需要 D10、10主、Dasha 支持，不能单独断成职业成就。

中置信：

> 若 10主/AmK/Moon 与 Ashwini 有关，同时 Ketu 定位星稳定，可判断此人适合急速响应、修复、医疗、咨询、技术启动、交通移动或开创型任务。

高置信：

> 当 Ashwini 落在职业链条，Ketu/Mars 状态强，D10 与 Dasha 同步激活时，可把“先锋-修复-快速行动”列为核心事业兑现风格。

## 3. Ketu 系星宿日模板

Ketu 主宰三宿：

| Nakshatra | 区间 | 基础主题 |
|---|---|---|
| Ashwini | Aries 0°00' - 13°20' | 快速启动、疗愈、急救、先锋 |
| Magha | Leo 0°00' - 13°20' | 祖先、权威、传承、名分 |
| Mula | Sagittarius 0°00' - 13°20' | 根源、拔除、研究、拆解 |

### Ketu 星宿日不是“绝对坏日”

应分任务类型判断：

适合：

- 断舍离
- 清理旧项目
- 修复、疗愈、急救
- 研究根源问题
- 祖先/传统/传承事务
- 非传统路径启动
- 冥想、修行、简化生活

谨慎：

- 大额投资
- 纯世俗炫耀型发布
- 需要长期稳定承诺的签约
- 情绪激烈时的分手/辞职/公开冲突
- 高风险交通与冒险活动

### 强制交叉

如果要给“宜/忌”建议，必须同时看：

1. 当日 Tithi / Vara / Yoga / Karana。
2. 月亮是否受严重克。
3. 是否与本命 Moon / Lagna / 10主 / 7主形成敏感触发。
4. 当前 Dasha 是否激活 Ketu、Ketu 定位星或目标宫主。
5. 任务性质是否与 Ketu 星宿主题同频。

## 4. Abhijit 使用边界

Abhijit 常被用于 Muhurta 中的特殊胜利窗口，但它不是普通 27 Nakshatra 列表中的常规人格星宿。

### 可以说

- Abhijit 更适合放在择时层使用。
- 可作为紧急场景下的“胜利/突破/保护性窗口”参考。
- 适合与 Tithi、Vara、Moon strength、Lagna、Tarabala、Chandrabala 共同评估。

### 不可以说

- 出生在 Abhijit 就一定富贵。
- Abhijit 可以覆盖所有 Muhurta 缺陷。
- Abhijit 等于任意时间都吉。
- Abhijit 单独决定婚姻、财富、事业结局。

### Abhijit Muhurta 输出模板

> Abhijit 可作为择时辅助窗口，尤其适合需要突破、启动、保护性推进的事务。但它必须与当天 Panchanga、月亮状态、Lagna、目标宫主共同判断；若 Dasha/Transit 明显冲突，Abhijit 只能降低风险，不能保证结果。

## 5. 与财富/天赋判断的连接

当用户问“天赋能不能赚钱”，不要只看 Ashwini/Abhijit/Ketu。

必须先确认：

1. 2宫、11宫、5宫、9宫、10宫。
2. 2主、11主、10主、Lagna lord。
3. Dhana Yoga、Lakshmi Yoga、Raja Yoga。
4. D2、D9、D10。
5. Yogi / Avayogi / Duplicate Yogi。
6. Dasha 与 Transit 是否激活。

若 Ashwini 或 Ketu 星宿参与财富链，可解释为：

- 快速启动型收入
- 修复/救援/咨询/疗愈收入
- 技术开荒型收入
- 旧资源清理后再利用
- 非传统职业或副业入口

若 Abhijit 参与择时，可解释为：

- 启动窗口
- 发布窗口
- 冲刺窗口
- 保护性推进窗口

但不能把它当作本命财富承诺。

## 7. 常见误判

1. **把 Ketu 星宿日都断成坏日**：错误。Ketu 更像切断、简化、修复、根源化。
2. **把 Ashwini 直接断成神医**：错误。必须有 6宫/10宫/职业星/分盘支持。
3. **把 Abhijit 当万能吉时**：错误。Muhurta 仍要看 Panchanga 与目标盘。
4. **把文章个案当经典规则**：错误。文章只能启发模板，不能替代权威链。
5. **忽略现实任务类型**：错误。择时必须先问“要做什么”，再判断 Nakshatra 是否同频。

```
1. 用户问天赋/择时/星宿日 → 先确认任务类型。

6. 输出必须说明来源等级与边界。
```
