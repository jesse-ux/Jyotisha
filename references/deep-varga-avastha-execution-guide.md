# Deep Varga Avastha 执行指南

> 版本：v1.0 | 2026-06-26
> 作用：说明当前 skill 中 `Deep Varga Avastha / Sayanadi-Shayanadi + D24/D30/D60` 的实际使用方式与边界。

## 一、当前已具备的能力

当前 skill 已有以下落地点：

1. `scripts/deep_varga_avastha.py`
2. `scripts/avastha_calculator.py`
3. `scripts/trimshamsa_d30.py`
4. `scripts/divisional_charts_extended.py`
5. API / 技术面：
   - `/api/deep_varga_avastha`

## 二、当前输出的核心结构

当前结果主要包含：

1. `avastha_summary`
2. `deep_varga_templates`
3. `priority_cards`
4. `headline`
5. `next_action`

重点分盘：

- `D24`：学习 / 证书 / 学术训练
- `D30`：压力 / 危机 / 风险 / 脆弱点
- `D60`：根层业力 / 深层背景主题

## 三、当前推荐执行顺序

1. **先看 avastha_summary**
   - 哪些行星强，哪些弱
   - 哪些处于 Nidra / Shayana / 弱 Bala 等状态
2. **再看 D24**
   - 学习、考试、导师、证书路径
3. **再看 D30**
   - 风险、冲突、脆弱面
4. **最后看 D60**
   - 只作背景主题，不要直接拿来做硬预测

## 四、当前真实边界

当前模块已经有较强的用户解释层，但必须保留以下边界：

1. `D60` 对出生时间极敏感
2. `Avastha` 更适合做状态解释层，不适合单独作为事件承诺器
3. `D24/D30/D60` 必须和 D1、Dasha、Transit 交叉
4. 不应把深分盘模板当作医学、法律、寿命的单独决策器

## 五、当前 skill 中的最佳角色

在当前 skill 里，Deep Varga Avastha 最适合做：

1. **高阶解释层**
2. **状态与背景层**
3. **风险提醒层**
4. **教育 / 危机 / 业力主题的补充层**

而不是：

1. 单独最终裁判
2. 精确日期级时机工具
3. 替代本命 promise 与 Dasha 的主引擎

## 六、当前推荐话术

- 适合说：
  - “D24 提示学习/考试风格与资源状态”
  - “D30 更像风险侧证，不是单独裁决器”
  - “D60 作为深层背景主题参考，需谨慎使用”
- 不适合直接说：
  - “深分盘已经单独完成全部精确预测闭环”
  - “只看 D60 就足以决定重大命题”
