# Antigravity AI Shadbala 六分量准确率战役 (Round 15)

Shadbala 是精密择时与择日的生命线，然而不同流派与计算标准使得其数值极其脆弱。以下为针对六大分量的战线盘点：

| 项 | 当前项目状态 | JHora/PyJHora/VedAstro 参考 | 缺口 | 下一步 |
|---|---|---|---|---|
| **Sthana (阵地力量)** | 粗算状态 | JHora 能细分为 5 层子项，要求对 Exaltation / Moolatrikona 等分级极严。 | 我们目前可能只是一个总权重估算，缺少精准子分量校验靶点。 | 必须在 validator 中增设子分项必填检查，并用 JHora 截图做硬对标。 |
| **Dig (方位力量)** | 粗算状态 | 取决于星体落入宫位或度数与特定方位的距离，需极高精度的天宫图。 | 当前黄经的小数点波动会导致该数值跳跃。 | 引入 VedAstro 的 Dig 结果做二次背书对照。 |
| **Kala (时间力量)** | 粗算状态 | 细分出白天/黑夜、时辰、旬、月、年力量，逻辑极为琐碎。 | 如果日出/日落时间存在标准差异，此项直接拉跨。 | 在 Evidence Packet 必须强记 `operator_note` 关于日出的定义偏好。 |
| **Chesta (视运动力量)** | 粗算状态 | 对逆行、留段计算要求极高。 | 系统可能仍未完全捕获星体加速/减速的微观瞬时状态。 | 增设针对木土星逆行的刁钻边界 Case。 |
| **Naisargika (先天力量)** | 常数级 | 各软件对此均为恒定常数比例。 | 无明显缺口。 | 静态常数对齐即可。 |
| **Drik (相位力量)** | 粗算状态 | 由特殊相位视差计算。 | 相位容许度的实现可能未对齐 JHora 的严苛曲线。 | 补充带有极端相位案例的截图靶向。 |
| **Rupa/Virupa total** | 占位符 | `shadbala_components` 目前只是一个无定形 JSON | 没有强制每个子维度都交卷，等于没对齐。 | 将底层 validator 从“有 JSON 即可”升级为“深层解构六项必须齐全”。 |
| **不允许全局缩放系数** | 🟢 已锁定 | `production_tuning_allowed: false` | 无法造假凑数。 | 保持不变，直面真实落差。 |
