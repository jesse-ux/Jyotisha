# Antigravity AI i18n 国际化翻译基础设施 (Round 28)

## 双语市场的需求
目前项目在努力适配中/英文，但代码中的星曜名字和概念经常杂糅着英文 (Sun) 和梵文音译 (Surya)。

## 规范字典
我们需要一个前端全局的 `i18n.json` 翻译库。
1. `Sun` -> `太阳` -> `Surya`
2. `Aries` -> `白羊座` -> `Mesha`
3. 用户在右上角应能切换显示模式：`English Only` / `梵文罗马音` / `中文简体`。
4. 特别是复杂的占星词汇，如 `Vargottama`，中文可以叫 `同分盘格局`。没有规范的翻译，中国用户会极其费解。

## 实施路径
Codex 不该负责翻译。这必须由懂得双语占星的人通过填 Excel 或 JSON 来完成映射。系统只需要在渲染前包一层 `t(key)` 即可。
