# Antigravity AI 解盘精准度评分系统 (Round 24)

由于无法依赖单一对错来衡量玄学，我们设计了一套加权打分法：

| 打分项 | 权重 | 评分标准与手段 |
|---|---|---|
| 1. 计算事实 | 25% | Dasha, 宫位, 星体落座必须与 JHora 分毫不差 (自动化比对)。 |
| 2. 规则引用 | 15% | AI 是否准确说出“因为火星落 7 宫，所以...”。(正则抽检) |
| 3. 强弱排序 | 10% | AI 是否优先提及 Shadbala 最高和最低的星。(自动化抽检) |
| 4. 事件时间窗口 | 20% | AI 断言的 Dasha 时间段，是否与名人真实传记时间吻合。(人工评审) |
| 5. 不确定性表达 | 10% | 没有乱下断语，包含“可能”、“受外部影响”。(LLM 情感分析) |
| 6. 不胡编 | 10% | 没有引用盘上根本不存在的星星相位。(交叉验证) |
| 7. 溯源 | 5% | 提示词或结果中标出 VedAstro 或 JHora 校验状态。 |
| 8. 用户反馈去污 | 5% | 排除用户的“巴纳姆效应”盲目五星好评。 |

**副手下一轮任务**：为上述 4 项“自动化比对”编写一个 `ai_response_grader.py` 伪代码。
**Codex 可做任务**：在 Prompt Pack 中强行注入一条命令：“请始终指出你的推断依据来源于哪颗星或哪个大运，不可凭空断言”。
