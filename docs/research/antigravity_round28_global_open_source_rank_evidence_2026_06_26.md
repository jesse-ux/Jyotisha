## 各维度评分与排位

| 评估维度 | 当前本项目状态 | 当前排名 | 行业第一是谁 | 冲第一路径 |
|---|---|---|---|---|
| **技法广度** | 68 核心项注册，涵盖 Dasha, Panchanga, Shadbala, Ashtakoot。 | 4 | PyJHora/JHora | 继续覆盖长尾条件如 35 种 Dasha，引入特殊卡拉卡。 |
| **传统深度** | 基础计算通过 18/18 不变量，但细节参数配置较少。 | 5 | JHora | 开放 Ayanamsa 细节配置，支持各种岁差和黄道模型。 |
| **API / Web 产品化** | 现代架构，干净的 JSON API，无历史包袱。 | **2** | VedAstro (C#) | 完成全技法 API 暴露，提供最流畅的 Swagger 文档。 |
| **AI 解盘能力** | 独创 Prompt Pack 护栏与证据链结构。 | **1** | 本项目 | 完善多维度的置信度标签，建立防幻觉体系。 |
| **中文体验** | 原生中文/梵文支持，UI 对国内友好。 | **1** | 本项目 | 提供高质量的中文古籍翻译工具提示。 |
| **测试 / Benchmark** | 首创 Accuracy CI 门禁体系。 | **1** | 本项目 | 将 Oracle 样本扩展至数百个。 |
| **License 可复用性** | 纯 MIT 结构，对商业极其友好。 | **1** | VedAstro/本项目 | 严格坚守隔离墙，吸收所有优质 MIT 逻辑。 |
| **外部 Oracle 对齐** | 有架构，但填入的样本仅限少量。 | 3 | PyJHora | 发动人工截取 AstroSage/Drik 靶标数据填入库中。 |

## 综合结论
保守估计，本项目在**现代化架构、AI 融合和商业友好度**上已经是开源界第一。但在**老派占星师看重的算法深度和冷门技法广度**上，仍落后于 JHora 和 PyJHora。
