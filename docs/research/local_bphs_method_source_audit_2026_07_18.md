# Local BPHS Method Source Audit

## Source boundary

The inspected copy is a locally held Chinese BPHS reading note. It is a
non-redistributable method source, not a licensed replacement for a published
critical edition. This audit records page labels and derived verification scope,
not book text or page images.

| 66 | Six components: Sthana, Dik, Kala, Chesta, Naisargika, Drik; seven classical planets only; 60 Virupa = 1 Rupa. | Component schema and unit contract. |

The pages contain formula/threshold material, but no single native chart with
birth input and all six computed component values. They cannot adjudicate the
existing 42 Shadbala component mismatches by themselves.
