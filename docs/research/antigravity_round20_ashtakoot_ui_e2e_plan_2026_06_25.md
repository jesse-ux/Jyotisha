# Antigravity AI Ashtakoot UI/E2E 用户流程计划 (Round 20)

| 场景编号 | 用户流程步骤 | 预期结果 | E2E 断言建议 |
|---|---|---|---|
| 1. 深度合盘 | 填写双方完整出生表单 | API 正确解析两份数据。 | 检查返回 JSON 存在两组 Nakshatra。 |
| 2. 快捷快算 | 仅输入男女双方月亮黄经 | 瞬间出分，不调用全盘引擎。 | 检查 UI 上的 36 分结果。 |
| 3. 无 API fallback | 断网时点击合盘 | PWA 计算引擎兜底，无报错。 | 拦截 fetch，确认仍能算出 36。 |
| 4. 深度组合 | API 连通时点击合盘 | 显示 Ashtakoot 与 D9 同步信息。 | 断言包含 `D9、Kuja Dosha` 文字。 |
| 5. 移动端适配 | 窄屏手机点击合盘卡片 | 按钮不溢出，表单单列排列。 | Viewport 375 下查宽高。 |
| 6. 总分呈现 | 计算结束 | 顶栏高亮显示 `xx / 36`。 | 获取 `<strong>` 里的得分数字。 |
| 7. 8 Kuta 细分 | 展开评判表 | 显示 Varna, Vashya, Tara 等 8 项得分。 | 检查 8 个行的存在。 |
| 8. Kuja Dosha | 查阅火星煞报告 | 显示双方火星是否中和。 | 查找 `Kuja Status` 字段。 |
| 9. 婚姻专题 | 查阅 D9 匹配度 | D9 Ascendant 轴线解析。 | 查找 `Navamsa` 同步逻辑。 |
| 10. 大运同步 | 查阅 Dasha | 提示两人的运势是否互相克制。 | 查找大运组合预警。 |
| 11. 保存案例 | 点击收藏 | 本地缓存 `Synastry Case`。 | 查 localStorage 是否多了一条。 |
| 12. 导出报告 | 下载 PDF | 报告中包含合盘专项表。 | 检查 PDF Blob 容量。 |
| 13. Prompt Pack | 复制 AI 提示词 | 包含对方的 Nakshatra 落点。 | 检查剪贴板拦截文本。 |
| 14. 错误拦截 | 故意输入 `380度` 黄经 | 红字提示 `请输入 0-360 之间的月亮黄经。` | 检查 `.synastry-error` DOM。 |
| 15. Oracle提示 | 点击合盘准确率 | 说明当前合盘算法对标于 VedAstro 库。 | 检查弹窗文本。 |

**落地建议**：重点优先把 14（错误拦截）和 2（快算）用 Playwright 覆盖。
