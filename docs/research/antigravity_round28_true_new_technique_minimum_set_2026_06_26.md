# Antigravity AI 当前项目“真新增技法”最小清单 (Round 28)

排除目前 `technique_registry.json` 中 68 个已经是 `covered` 或 `complete` 的技法后，这些是**真正需要从头手写算法或抄常量的数学荒漠**：

1. **Pancha Pakshi (五鸟占卜)**：南印神技。依赖精确到秒的地方时、月相和星期几。目前完全没代码。
2. **Sarvato Bhadra Chakra (SBC)**：用于股票和个人运势预测的 9x9 复杂网格。目前代码为 0。
3. **Kota Chakra**：判断法庭官司胜负、健康疾病抵抗力的堡垒图。完全没代码。
4. **Kalachakra Dasha**：大运计算。它的轮盘规则非常复杂，与目前的树状结构不太兼容。
5. **Nadi Astrology 基础算法**：如 Bhrigu Nandi Nadi 的行星相位连接法。与 Parashara 完全不同，目前没代码。
6. **Saham (阿拉伯点)**：如 Punya Saham, Vidya Saham。Tajika 体系的延伸。
7. **Papasamya**：男女双方凶星力量加权计分，合婚的另一种视角。
8. **Upagrahas (副星/虚星)**：Mandi, Gulika, Dhooma 等的精确落点计算，用于推算非自然死亡或深层心理。

## 开发建议
不要让 Codex 一口气把这 8 个全写了。挑一个 ROI 最高的（如 **Pancha Pakshi** 或 **Saham**）进行下一轮突击。
