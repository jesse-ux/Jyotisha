# Antigravity AI 隐私与 PII 数据保护审计 (Round 28)

## 安全风险
算命系统天生涉及极其敏感的 PII（个人身份信息）：姓名、精确到分钟的出生地、出生时间。

## 审计点
1. 我们的数据库存了这些吗？目前是完全无状态的，前端发数据，后端算完即毁。**极其安全**。
2. AI 调用风险：如果后端调用 OpenAI 来解盘，Payload 里**绝不能**包含用户的真实姓名。最好连地点都不要给精确地名，只给时区或模糊化为“某个亚洲城市”。
3. 外部 Oracle 样本：存放在库里的截图（如 Virat 这种公众人物没事），如果是普通人样本，必须给姓名和详细坐标打马赛克，只保留数字本身。
